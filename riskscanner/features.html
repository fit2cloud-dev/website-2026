RiskScanner 功能介绍

演示视频

功能列表

首页
概览

首页概览实时展示扫描资源的不合规数量与占比

实时展示不合规扫描规则

实时展示云账号扫描评分与资源数量

实时展示区域不合规资源数量
历史记录

记录并展示每个云账号每日的最终扫描记录与扫描资源数量
活动

展示用户在平台的所有操作记录
扫描规则
扫描规则

系统内置云平台对应的 custodian 类型的规则，规则内容以 yaml 格式编写，不可增删改

用户自定义云平台对应的 custodian 类型的规则，规则内容以 yaml 格式编写，可增删改查
规则标签

系统内置规则标签，给规则定义标签，不可增删改

用户自定义规则标签，给规则定义标签，可增删改查
规则组

系统内置规则组，给规则分组，不可增删改

用户自定义规则组，给规则分组，可增删改查
扫描结果
扫描结果

根据云平台扫描规则，扫描资源并生成扫描结果，查看扫描状态、扫描日志

查看扫描结果的不合规资源的详细信息
合规报告

根据规则组、等保预检等分组显示扫描结果，根据风险条例显示扫描资源的结果与优化改进建议

下载合规报告
云账号
云账号设置

创建、编辑云平台的云账号

一键扫描、一键校验、获取区域等
定时任务

根据云账号或规则创建扫描定时任务

暂停启动定时任务，查看扫描详情、查看定时任务日志
统计分析

根据云账号查看统计结果

根据扫描规则、规则组别、等保条例、规则标签、扫描区域、扫描资源等维度查看扫描结果统计
系统设置
用户管理

创建、编辑、删除用户信息
系统参数设置

设置邮件、企业微信、钉钉等信息
消息通知

支持对安全合规规则扫描资源结果进行、邮件、企业微信、钉钉等消息通知
代理设置

创建 http 或 https 类型的代理供云账号扫描使用
个人设置

编辑用户、修改密码
API Keys

创建 Access Key 与 Securet Keys 供 Restful APIs 调用使用

演示视频

快速演示如何通过 RiskScanner 实现对主流公(私)有云资源的安全合规扫描及使用优化建议
